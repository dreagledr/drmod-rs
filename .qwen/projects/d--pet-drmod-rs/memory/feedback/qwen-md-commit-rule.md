description: Перед каждым коммитом проверять и актуализировать QWEN.md
type: feedback
---

Перед каждым коммитом проверять актуальность `QWEN.md`. Если изменения затрагивают архитектуру, зависимости, новые модули, референсы, memory offsets, или любую информацию из этого файла — обновить соответствующие секции в том же коммите.

**Why:** QWEN.md — источник контекста для AI-ассистента. Устаревший QWEN.md ведёт к неверным предположениям о кодовой базе.

**How to apply:** при подготовке коммита добавить в чек-лист: `git diff HEAD` → проверить, затронуты ли темы из QWEN.md → обновить при необходимости.
